# Sistema de Gerenciamento de Eventos e Cursos

Este projeto é um sistema web para gerenciamento de eventos e cursos, desenvolvido em **PHP**, utilizando **MySQL** como banco de dados e estilização com **CSS**.

## 📌 Funcionalidades
- 📅 Cadastro e gerenciamento de eventos e cursos.
- 👥 Registro de usuários com diferentes níveis de acesso.
- 📝 Inscrição de usuários nos eventos/cursos.
- 📊 Relatórios de eventos, cursos e inscrições.
- 🏆 Sistema de ranking para participantes.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** PHP
- **Banco de Dados:** MySQL
- **Front-end:** HTML, CSS
- **Estilização:** CSS puro

## 🚀 Como Configurar
1. Clone o repositório:
   ```sh
   git clone https://github.com/seuusuario/projeto_final.git
   ```
2. Configure o banco de dados usando o arquivo `eventcontroldb.sql` encontrado na pasta `includes`.
3. Atualize o arquivo `conexao.php` com suas credenciais do banco de dados.
4. Suba o projeto em um servidor local (XAMPP, WAMP, MAMP ou LAMP).
5. Acesse `http://localhost/projeto_final` no navegador.
